# Comparative analysis of deep learning model outputs using different fine-tuning methods
## Spring 2026 
## Applying Deep Learning to Earth Observation Overview 
## Project Description: We are researching the effect of different fine-tuning methods on a pre-trained model called Fieldmapper. Fieldmapper is a toolkit that uses semantic segmentation on cropland using images from satellites. The data set we will be using is called mapping-africa and contains cropland images from Africa. Our goal is to compare and contrast these different methods by visualizing their feature maps. 
## The fine-tuning strategies we are thinking of using include freezing the whole encoder, only freezing the early layers of the encoder, and progressively freezing the encoder.
