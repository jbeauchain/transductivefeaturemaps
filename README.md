# Comparative analysis of deep learning model outputs using different fine-tuning methods
### Spring 2026 
### Applying Deep Learning to Earth Observation 
## By Jenna Beauchain, Charlotte Burbridge, Andre Bergeron

## Project Description: 
We are researching the effect of different fine-tuning methods on a pre-trained model called Fieldmapper. Fieldmapper is a toolkit that uses semantic segmentation on cropland using images from satellites. The data set we will be using is called mapping-africa and contains cropland images from Africa. Our project focuses on three types of finetuning; frozen-layer finetuning, progressive finetuning, and no finetuning or a baseline method. Our project runs the model with each of these methods and compares them using matplotlib.
